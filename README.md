# Las raíces que perdimos

Sitio web de humanismo de datos sobre la pérdida de cobertura arbórea en México por estado (2001-2025).
Entrega final de Visualización de Datos · Universidad Anáhuac México Norte · Raúl Cruz Muñoz (ID 00576757).

## Estructura
- `index.html`: el sitio (portada, árbol, raíces, escenario hipotético, conclusión y fuentes).
- `css/styles.css` y `js/main.js`: diseño e interacción.
- `data/datos_limpios.csv`: conjunto de datos de la Entrega 1 (sin cambios). La longitud de cada raíz es la columna `Altura_Barra_PX`.
- `data/contexto.csv`: municipio más afectado y contexto humano por estado.
- `data/perdida_anual_mexico.csv`: pérdida nacional por año (para el árbol).
- `assets/`: opcional, `bosque.mp4` para el video de fondo de la portada.

Fuente de los datos: Global Forest Watch / Universidad de Maryland (2026).
